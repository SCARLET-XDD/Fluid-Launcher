# Fluid Launcher
Spring-physics launcher with One UI-style visuals.

## Build the APK (no Android Studio)
1. Create a free GitHub repo and upload this whole folder (keep the .github folder).
2. Go to the Actions tab > "Build APK" > wait ~4 min.
3. Download the `FluidLauncher-apk` artifact, unzip, install the APK on your phone
   (allow "install unknown apps").
4. Press Home > choose Fluid Launcher > Always.

## Build with Android Studio
Open the folder, let Gradle sync, then Build > Build APK(s).

## Use
- Swipe up: app drawer. Swipe the handle down / Back: close.
- Long-press an app: pin/unpin on dock (max 5).
